Bonding Potion · Art editor

This editor needs Chrome or Edge on a computer (it saves files into your project folder). Firefox and Safari can't do that. The game itself works in every browser.

How it works

  1. Click Choose project folder… and select the bonding_potion folder (the one with index.html and data). Allow the browser to edit files.
  2. Drop a finished image onto its card, or drop many files anywhere on the page: files named like the Art List (e.g. heroine.png) are matched automatically.
  3. The editor checks the size, offers to fit or crop if needed, saves the file under the right name and format, and keeps a backup in .backup/.
  4. When you're done, commit and push in GitHub Desktop. The live game updates in about a minute.
