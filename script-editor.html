Bonding Potion · Script editor

Unsaved changes
This editor needs Chrome or Edge on a computer (it saves files into your project folder). Firefox and Safari can't do that. The game itself works in every browser.

How it works

  1. Click Choose project folder… and select the bonding_potion folder (the one with index.html and data). Allow the browser to edit files.
  2. Pick a scene on the left. Change lines, who says them and their emotion; add, delete and drag rows to reorder them; make characters appear and disappear.
  3. Only if… on a row sets a condition: the row is used only when the player brewed a potion with the cat's or the book recipe, or used the cat's recipe a certain number of times.
  4. Click Save (Ctrl+S). The editor writes data/script.txt and keeps the old version in .backup/. Then Play the scene to check it.

Images are replaced in the separate Art editor.

    Characters

    The name is shown above the textbox when the character speaks. Emotions are extra images: a line with an emotion shows that image instead of the default one. New emotions get a temporary image that you replace with final art in the Art editor.

    Problems found in the script ()

      Only if…

      The row is used only when all these are true. With no conditions it's always used.

      Test choices

      When you press Play, the game pretends these potions were already brewed like this. Useful to check rows with conditions.

      New emotion for

      One word, small letters, for example happy, angry, sad. The editor creates a temporary image for the artist to replace.
